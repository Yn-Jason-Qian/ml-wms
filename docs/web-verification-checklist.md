## 已知限制（非 Bug）

1. 部分需要已存在数据关联的操作（如收货需先有 ASN、上架需先有收货单），首次使用时这些操作会提示"数据不存在"，属于正常预期
2. 仪表盘的库龄饼图和作业效率柱状图为模拟数据，暂未接真实 API
3. 库存查询的 `locationCode` 字段后端暂未返回，显示为空
4. 全局搜索仅匹配 ASN 号/订单号/SKU 编码/库位编码，不匹配中文名称
